# Open decisions before the first real pilot

These decisions must be confirmed rather than inferred from the user's approximate location or a demo seed.

1. **Deployment geography:** Which state(s), districts and blocks are in the first deployment geography? Bihar is a possibility, not yet a confirmed launch scope.
2. **Launch languages:** Which languages must be ready on day one? Hindi, Bhojpuri, Maithili, Bangla and English are candidate languages only; confirm the actual list and local dialect variants with native speakers.
3. **Operating organisation:** Which organisation will operate the platform and be accountable for patient data and support?
4. **Local partners:** Which facilities, clinicians, pharmacies and community health worker groups have agreed to participate?
5. **Emergency pathways:** What verified emergency numbers and referral pathways apply in each service area?
6. **Clinical scope:** Is the first release limited to appointment/referral coordination, or will clinician-led telemedicine be included from day one?
7. **Vendors:** Which SMS, video, maps and hosting vendors are approved, and what are their data-processing terms?
8. **Data governance:** Who is the data fiduciary/controller, who handles grievances, and what are the retention/deletion periods?

The current local seed uses fictional `Demo State / Demo District / Demo Block / Demo Village` data. The mobile shell has only a Hindi/English development UI. Neither is a declaration of the launch geography or language set.
